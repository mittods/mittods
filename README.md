## 🚀 Proyectos Destacados

### [Di-Judge](https://github.com/mittods/di-judge) — Juez Virtual para Programación Competitiva

Plataforma institucional de evaluación automática de código para la UACh. Optimizada con técnicas HPC: cache con `mmap`, módulos nativos C++ con `pybind11` y paralelismo multinúcleo con OpenMP.

`Python` `C++` `pybind11` `OpenMP` `Docker` `Linux`

### Valdiv-IA — Asistente Conversacional

Asistente conversacional orientado a la ciudad de Valdivia, desarrollado en equipo bajo metodología Scrum. Implementa un sistema RAG con base vectorial Redis y modelos generativos. Desplegado en servidor institucional con Docker.

`React` `Vite` `Chakra UI` `Redis` `Docker` `RAG`
